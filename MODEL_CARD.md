# Model and explanation card

## Intended purpose

This synthetic binary-classification benchmark tests an XAI audit pipeline. It must not be used for lending, eligibility, employment, insurance, or any decision about a person.

## Data

All rows are generated by `sklearn.datasets.make_classification`. Feature names are explicitly labelled as proxies. `audit_group` is a deterministic synthetic slice label and is excluded from model features.

## Model and explanation

The Java example is a transparent logistic risk model. Its local explanation decomposes log-odds into exact feature contributions relative to a declared baseline. This verifies metric implementation but is not a causal explanation and does not establish usefulness for an intended human audience.

## Evaluation

- reconstruction mean absolute error as a limited fidelity diagnostic;
- top-3 Jaccard and Spearman rank stability after small perturbations;
- between-group gap in local reconstruction error;
- documentation checks linked to a versioned regulatory crosswalk.

The thresholds are declared research choices. Passing one is evidence for review, not proof of compliance, fairness, usefulness, or safety.
